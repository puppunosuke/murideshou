# 無理でしょ — プロトタイプ

> 応援されるより、疑われたほうが人は動く。

ハッカソン（テーマ「ワクワク」）向けアイデアの画面プロト。
**見た目と画面遷移を確認するためのモック**で、サーバもAIも繋いでいない。

## 開くには

公開版: <https://puppunosuke.github.io/murideshou/>

ローカルで見る場合は `index.html` をブラウザで直接開く（ビルド・サーバ不要）。

## コンセプト

ワクワクは「不確実性 × 期待がプラス」の状態で、**結果が出る前にしか存在しない**。
そこで、宣言した本人ではなく**周りが賭ける**構造にして、他人の未来を共有可能な不確実性に変える。

構造上の反転が3つある。

1. **本人は賭けられない。** 観客だけが賭ける。当事者に金銭的利害がないので、賭博性の問題がほぼ消える
2. **本人が見るのはオッズ1つだけ。** 誰がいくら賭けたかは見えない。数字だけが静かに突きつけられる
3. **達成すると「最大の疑い手」が表彰される。** 負けた人が主役になるので、疑うことが罪でなく参加になる

## 画面遷移

```
空 ─→ 宣言 ─→ 審査 ─┬─ 却下 ─→ 宣言へ戻る
                     └─ 受理 ─→ オッズ ─→ 証拠 ─→ 結果
                                   ↑
                                  賭場（観客が1タップで賭ける）
```

タブは「自分」と「賭場」の2つだけ。

## 実装されていること

- 宣言の審査（`app.js` の `review()`）。**証明できない宣言は却下される**。「やる気を出す」を入れると弾かれる
- パリミュチュエル方式のオッズ計算（`odds()`）。総プール ÷ その側のプール。胴元の取り分ゼロ
- 賭けるとプールが増えてオッズが即再計算される
- 証拠提出 → 一次判定の進行 → 配当と最大の疑い手

**モックのままの部分**（本番ではここが実装になる）

- 宣言の審査と証拠の照合は、キーワード辞書で代用している。本番はLLMのマルチモーダル呼び出し
- 異議申し立て（外した人だけが申し立てられる仕組み）は未実装。設計だけある
- ポイント残高・賭け回数はページを閉じると消える。永続化なし

## デモ操作パネル

端末フレームの外にある開発用パネル。実際のアプリには存在しない。
「観客の賭けを流す」でオッズが動き、「締切まで進める」で判定へ進める。
判定の結末（達成／失敗）も切り替えられる。

## このプロダクトのデザイン宣言

**`design/design-principles.md` から全面的に逸脱している（拓男承認済み）。**
白地・グロー禁止・影禁止といったワークスペース共通の原則は、このプロダクトだけ外す。
賭けが起きている場であることを見た目で言い切るため、
**競馬場・ブックメーカーの電光オッズボード**を軸に、カジノの緑と金を差した。

- **地**: 深夜の黒（`#0A0A0B`）× カジノテーブルのフェルト緑（`#0B3D2E`）
- **主役**: アンバー（`#FFB100`）のLED発光。倍率の数字だけが光る
- **色の意味**: やる＝緑 / 無理でしょ＝赤 / 金＝場の格式。すべて意味を持つ
- **逸脱の内訳**: 暗地、テキストグロー、box-shadow、グラデーション、112pxの数字
- **原則から残したもの**: 角0（掲示板は角が立っている）、8pxスケール、タイポの階層、
  一覧と詳細を分離する構造

賭場はフェルト緑、オッズ画面と結果画面は黒地。オッズ画面には LIVE ランプと
前回比の変動（▲0.28 もっと疑われた）が出て、更新の瞬間に数字が一度白く光る。

## 検証

Playwright（Python版）で実挙動を確認済み。27項目パス。

- 却下・受理の分岐、5画面の遷移
- プール100/100 → 2.00倍、賭け流入後 2.0 → 3.8倍
- 賭場でのベットによるオッズ再計算（3.95 → 4.51）と残回数の減少
- 賭場の独立スクロール（横はみ出しゼロ）
- 390px幅での横スクロールなし、JSエラーなし
